# OverTheWire Bandit

A hands-on Linux command-line project using the OverTheWire Bandit wargame to develop practical Linux and troubleshooting skills.

## Skills Practiced

- Linux command line
- SSH
- File permissions
- File and directory manipulation
- Searching and text processing
- Compression and archiving
- Bash
- Networking
- Troubleshooting
